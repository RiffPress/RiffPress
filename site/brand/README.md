# Riff's brand

**The mark** is a tuning fork, for musical precision: the two *f*s of the wordmark, joined below the baseline into one handle. It is drawn from EB Garamond's own *f* at weight 500. Two of them stand 300 units apart, each cut just above its foot serif, where the stem runs straight. Their crossbars meet as one, and the first *f*'s hook stops short of the second stem. A half ring the stem's width (91.5 units) joins them, and a handle of the same width drops to the descender line.

**The wordmark** is *Ri* in EB Garamond 500, then the mark as its *ff*. Every file is outlines, so nothing depends on the font being installed.

**Colour** is Riff's amber, `#ffb020`, on charcoal: `#1e1e1e`, or the app's `#121212`. On a light ground, amber is too pale to read as text, so links and outline buttons there use a deep amber, `#9a5b00` (5.4:1 on white). Filled buttons stay amber, with charcoal on them. There is no blue.

**Type** is wordpress.org's: EB Garamond for headings and Inter for text.
