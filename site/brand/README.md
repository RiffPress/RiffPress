# Riff's brand

**The mark** is ***ff***, as a score writes *fortissimo*, made into a tuning fork: the two *f*s of the wordmark, joined below the baseline into one handle. It's the end of the name, the loudest marking in music, and the tool that holds a pitch exactly. It's drawn from EB Garamond Italic's own *ff* ligature at weight 500, so the first *f*'s arm meets the second as the typeface draws it. The ligature is cut at 100 units, above its italic tails. A half ring the stems' width (84.5 units) joins them, and a handle of the same width drops to 330 below the baseline. The bend and the handle are drawn upright, then slanted with the stems (100 across for every 350 up, about 16°), so the fork leans as one.

**The wordmark** is *Ri* in EB Garamond Italic 500, then the mark as its *ff*. Every file is outlines, so nothing depends on the font being installed.

**Colour** is Riff's amber, `#ffb020`, on charcoal: `#1e1e1e`, or the app's `#121212`. On a light ground, amber is too pale to read as text, so links and outline buttons there use a deep amber, `#9a5b00` (5.4:1 on white). Filled buttons stay amber, with charcoal on them. There is no blue.

**Type** is wordpress.org's: EB Garamond for headings and Inter for text.
