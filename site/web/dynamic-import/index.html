Dynamic import

Loads the Listen app only on the page that holds the block.

How Riff uses it

After the player is ready it checks for the Listen block and a module URL the feature put into the page data. Only then does it import() the app and call its start function with the public API. Posts without the block never download it.

Why

A static import would load the app on every post with audio.

Without it

A failed import leaves the server-rendered links as real links, so the library works as plain page loads.

Where

  • plugins/riff/assets/riff.js, line 3023
