matchMedia

Reads the same breakpoint and motion preference the stylesheet uses.

How Riff uses it

Three queries are read from script. prefers-reduced-motion skips the frame loops and the close transition. (hover: none) stands in for a touch screen before vibrating. (min-width: 900px) decides whether the bar sits beside the dialog and stays live, or under it and goes inert.

Why

The phone and desktop layouts differ in ways CSS alone cannot express, and the script has to agree with the stylesheet about where the line is.
