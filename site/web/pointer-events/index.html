Pointer Events

One gesture helper for swiping the bar and dragging the sheets.

How Riff uses it

A single drag() helper records the pointer's start, timestamp and id on pointerdown. It reports deltas on pointermove for that pointer, and calls an end handler on pointerup or pointercancel with distance and velocity. It skips mouse pointers. It drives swiping the bar to skip or dismiss, dragging Now Playing down to close, and dragging the Up next handle.

Why

Pointer events give one code path for touch and pen with a pointerType to exclude the mouse.
