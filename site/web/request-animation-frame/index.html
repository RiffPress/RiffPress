requestAnimationFrame

Moves the seek line and the filament every frame, not four times a second.

How Riff uses it

Two frame loops run while music plays. One repaints the seek line and times every frame and stops when the element pauses or the page hides. The other advances the filament's heat model with the frame timestamp and reads the analyser. Opening Now Playing also waits one frame before adding its class, so the slide-up transition actually runs.

Why

timeupdate fires about four times a second and reads as a line that skips.
